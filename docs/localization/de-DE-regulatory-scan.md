# Regulatory Scan — Allemagne — de-DE

## 1. Objectif du scan réglementaire

Ce scan réglementaire prépare la future localisation allemande de Certif-Scope pour le marché Allemagne (`de-DE`) sans créer de route `/de/`, sans traduire le site et sans modifier le produit.

Le document identifie les cadres réglementaires et institutionnels qui peuvent influencer le wording allemand : CSRD, ESRS, EU Taxonomy, allégations environnementales, communication environnementale allemande, procurement, banque, assurance, protection des données et limites de la méthode spend-based.

Ce scan ne conclut jamais que Certif-Scope est conforme à une réglementation. Il sert uniquement à définir les risques de formulation, les termes dangereux, les formulations prudentes et les impacts concrets pour les futures pages allemandes.

Date de cadrage : 20 juin 2026.

## 3. Synthèse exécutive prudente

Certif-Scope peut être présenté en allemand comme un document carbone indicatif, standardisé, daté, archivable et vérifiable sur le plan documentaire.

Certif-Scope ne doit pas être présenté comme une certification, un audit, une preuve réglementaire, un reporting CSRD/ESRS, une déclaration taxonomique ou une garantie de conformité.

La version allemande devra être très prudente sur les claims environnementaux. Les termes liés à la neutralité carbone, à la compensation, au zéro émission, à la certification, à l'officialité ou à la reconnaissance par une autorité doivent être évités.

Le wording allemand doit insister sur :

- le caractère indicatif de l'estimation ;
- la méthode spend-based ;
- l'absence d'audit et de certification ;
- la responsabilité de l'utilisateur sur les données déclarées ;
- l'absence de conservation des données financières détaillées ;
- la différence entre demande documentaire privée et obligation réglementaire.

## 4. CSRD — points à prendre en compte

La CSRD est le cadre européen de reporting de durabilité pour les entreprises dans son champ d'application. Les entreprises concernées doivent produire des informations de durabilité structurées selon des standards européens. Le périmètre, le calendrier et les modalités d'application doivent être vérifiés au moment de publication, car les textes européens et leur mise en œuvre nationale peuvent évoluer.

Pour l'Allemagne, le wording doit distinguer trois situations :

- obligation réglementaire de reporting pour les entreprises effectivement dans le champ ;
- demandes indirectes de clients, fournisseurs, banques ou donneurs d'ordre ;
- demande documentaire privée où un document indicatif peut aider à répondre rapidement sans remplacer un reporting obligatoire.

Impacts pour Certif-Scope :

- Certif-Scope peut évoquer le contexte des demandes de durabilité dans les chaînes de valeur.
- Certif-Scope ne doit jamais dire qu'il rend une entreprise conforme CSRD.
- Certif-Scope ne doit jamais promettre de satisfaire une obligation de reporting.
- Certif-Scope doit éviter de généraliser une obligation à toutes les PME allemandes.

| Wording allemand recommandé | Usage |
| --- | --- |
| `im Kontext zunehmender Nachhaltigkeitsanfragen` | Pour évoquer le contexte de marché sans créer d'obligation. |
| `für einfache Dokumentationsanfragen` | Pour limiter l'usage à une demande documentaire simple. |
| `nicht als CSRD-Bericht geeignet` | Pour distinguer explicitement l'attestation du reporting. |
| `kein Ersatz für eine gesetzliche Nachhaltigkeitsberichterstattung` | Pour les disclaimers. |

| Wording allemand interdit | Risque |
| --- | --- |
| `CSRD-konform` | Promesse de conformité. |
| `erfüllt die CSRD-Pflicht` | Promesse de satisfaction d'une obligation. |
| `CSRD-Nachweis` | Confusion preuve documentaire privée / reporting réglementaire. |
| `rechtssicherer CSRD-Bericht` | Promesse juridique excessive. |

## 5. ESRS — points à prendre en compte

Les ESRS sont les European Sustainability Reporting Standards associés au reporting de durabilité des entreprises dans le champ CSRD. Ils sont développés techniquement avec EFRAG et adoptés dans le cadre européen applicable.

Certif-Scope ne produit pas un reporting ESRS complet. L'attestation ne couvre pas la matérialité, la gouvernance, la stratégie, les politiques, les métriques détaillées, les datapoints ESRS ni les procédures de reporting exigées pour les entreprises concernées.

Risques principaux :

- utiliser `ESRS-konform` ;
- laisser penser que l'attestation est un `Nachhaltigkeitsbericht` ;
- présenter une estimation CO2e agrégée comme réponse complète à ESRS E1 ;
- suggérer que le PDF remplace des processus internes de reporting.

Formulations prudentes :

| Formulation | Usage |
| --- | --- |
| `kein ESRS-Reporting` | Mention de limite claire. |
| `nicht als Nachhaltigkeitsbericht nach ESRS gedacht` | Page méthodologie ou conformité. |
| `indikative CO2e-Schätzung außerhalb eines vollständigen ESRS-Berichts` | Explication longue. |
| `kann eine einfache Anfrage unterstützen, ersetzt aber keine ESRS-Berichtspflichten` | FAQ et pages use case. |

## 6. EU Taxonomy — points à prendre en compte

L'EU Taxonomy est un cadre de classification des activités économiques durables dans le contexte de la finance durable européenne. Elle sert notamment à la transparence des activités économiques alignées avec des critères techniques.

Certif-Scope ne doit pas être présenté comme un outil de reporting taxonomique. Le produit ne classe pas une activité selon les critères de la Taxonomie, ne calcule pas des KPI taxonomiques et ne vérifie pas l'alignement d'une activité.

Implications wording :

- ne pas utiliser `taxonomiekonform` ;
- ne pas promettre d'alignement EU Taxonomy ;
- ne pas associer l'attestation à une validation d'activité durable ;
- si la Taxonomie est mentionnée, le faire uniquement comme contexte réglementaire à vérifier.

Formulation prudente possible :

`Certif-Scope erstellt keine EU-Taxonomie-Berichterstattung und bewertet keine Taxonomie-Konformität.`

## 7. Green Claims et allégations environnementales

Les allégations environnementales doivent être prudentes, substantiées et non trompeuses. Les sources européennes et allemandes indiquent une vigilance renforcée contre les communications environnementales vagues ou excessives.

Pour Certif-Scope, les termes suivants doivent être évités dans la future version allemande :

- `klimaneutral` ;
- `CO2-neutral` ;
- `emissionsfrei` ;
- `kompensiert` ;
- `garantiert` ;
- `zertifiziert` ;
- `offiziell anerkannt` ;
- `geprüft` lorsque cela peut être lu comme audit externe.

Formulations prudentes :

- `indikative CO2e-Schätzung` ;
- `standardisiertes CO2e-Dokument` ;
- `dokumentarisch prüfbar` ;
- `auf aggregierten Ausgaben basierend` ;
- `keine Aussage zur Klimaneutralität` ;
- `keine Kompensation und keine Zertifizierung`.

La page allemande devra éviter les slogans de performance environnementale et préférer un discours factuel sur le type de document, la méthode et les limites.

## 8. Allemagne — communication environnementale et concurrence

En Allemagne, les communications environnementales B2B doivent être claires, vérifiables et non ambiguës. Les risques de greenwashing concernent surtout les formulations larges ou valorisantes qui peuvent être comprises comme des garanties.

Recommandations :

- expliquer les limites près des CTAs ;
- indiquer que le résultat est une estimation ;
- ne pas utiliser un vocabulaire de certification ;
- éviter toute confusion entre document privé et preuve officielle ;
- utiliser des formulations sobres et techniques ;
- réserver les références réglementaires à des pages explicatives, jamais comme promesse produit.

À éviter :

- `rechtssicher` ;
- `offiziell` ;
- `anerkannt` ;
- `gesetzlich gültig` ;
- `garantierte ESG-Konformität` ;
- `vollständiger Klimanachweis`.

## 9. Allemagne — PME, Mittelstand et demandes fournisseurs

Le contexte allemand peut inclure des demandes documentaires adressées aux PME par des clients, fournisseurs, donneurs d'ordre ou acteurs de la chaîne de valeur. Ces demandes ne sont pas nécessairement des obligations réglementaires directes.

Positionnement prudent :

- Certif-Scope peut être utile pour une demande simple de documentation CO2e.
- Certif-Scope peut aider à fournir un résultat agrégé et une méthode indiquée.
- Certif-Scope ne doit pas être présenté comme obligatoire pour toutes les PME allemandes.
- Certif-Scope ne doit pas être présenté comme suffisant lorsque le client exige un audit, un inventaire GES complet ou un reporting réglementaire.

Wording recommandé :

`für einfache CO2e-Dokumentationsanfragen von Kunden, Lieferanten oder Geschäftspartnern`

Wording à éviter :

`Pflichtnachweis für alle KMU`

## 10. Allemagne — marchés publics et appels d'offres

Les appels d'offres peuvent inclure des exigences environnementales ou de durabilité, notamment selon le type de marché et le donneur d'ordre. Ces exigences sont spécifiques au dossier et ne doivent pas être généralisées.

Distinction obligatoire :

- une exigence spécifique d'un donneur d'ordre peut demander un document carbone ;
- cela ne signifie pas que Certif-Scope constitue une preuve réglementaire générale ;
- si l'appel d'offres impose un audit, une certification ou une norme précise, Certif-Scope ne doit pas être présenté comme équivalent.

Formulations prudentes :

| Terme | Usage |
| --- | --- |
| `Ausschreibung` | Utilisable pour le contexte d'appel d'offres. |
| `Vergabeunterlagen` | Utilisable pour les dossiers de marché. |
| `Lieferantennachweis` | Utilisable seulement avec limite documentaire. |
| `unterstützendes Dokument` | Recommandé pour éviter la surpromesse. |

Formulation recommandée :

`kann als unterstützendes CO2e-Dokument für einfache Ausschreibungsunterlagen dienen, sofern keine spezifische Prüfung oder Zertifizierung verlangt wird`

## 11. Allemagne — banques, ESG et financement

Les banques et acteurs financiers peuvent demander des informations ESG ou carbone dans certains dossiers. Ce contexte ne signifie pas qu'un document Certif-Scope sera accepté, ni qu'il améliore un score ou garantit un financement.

Risques :

- promettre une acceptation bancaire ;
- suggérer un scoring ESG ;
- dire que le document satisfait des exigences BaFin ;
- présenter le PDF comme preuve financière réglementaire.

Wording recommandé :

`für einfache ESG- oder CO2e-bezogene Bankunterlagen`

`kann eine erste dokumentarische Einordnung unterstützen`

Wording interdit :

- `garantiert bessere Finanzierungskonditionen` ;
- `von Banken anerkannt` ;
- `BaFin-konform` ;
- `ESG-Score verbessert`.

## 12. Allemagne — assurances et dossiers professionnels

Certaines assurances professionnelles peuvent demander des informations ESG ou environnementales selon le secteur, le risque ou le dossier. Certif-Scope peut être positionné comme document indicatif, mais aucune acceptation automatique ne doit être suggérée.

À ne pas promettre :

- réduction de prime ;
- acceptation automatique ;
- conformité exigée ;
- validation de risque ;
- audit assurantiel.

Wording recommandé :

`für einfache Unterlagen gegenüber Versicherern oder Geschäftspartnern`

`kein Versicherungsnachweis und keine Risikoprüfung`

## 13. RGPD / DSGVO et données

La future version allemande devra être très précise sur la protection des données. Le wording doit distinguer les données d'entrée, le résultat agrégé, l'attestation PDF et les processeurs techniques strictement nécessaires.

Points à préserver :

- minimisation des données ;
- traitement limité à la génération du document ;
- absence de conservation des données financières détaillées par Certif-Scope ;
- responsabilité de l'utilisateur sur l'exactitude des données saisies ;
- distinction entre données d'entrée et PDF généré ;
- transparence sur les prestataires techniques nécessaires.

Formulations allemandes recommandées :

| Formulation | Usage |
| --- | --- |
| `Datenschutz durch Datensparsamkeit` | Privacy / formulaire. |
| `lokale Verarbeitung der Eingabedaten, soweit technisch vorgesehen` | À utiliser seulement si confirmé par le flux technique. |
| `keine Speicherung detaillierter Finanzdaten durch Certif-Scope` | Promesse privacy centrale. |
| `nur die für die PDF-Erstellung erforderlichen Daten` | Processeurs techniques. |
| `Zahlungsdaten werden durch den Zahlungsdienstleister verarbeitet` | Stripe / paiement. |
| `das ausgestellte PDF ist vom Nutzer selbst zu speichern` | Success / PDF. |

À éviter :

- `keine Datenverarbeitung durch Dritte` si des processeurs techniques sont utilisés ;
- `vollständig anonym` si les données incluent nom d'entreprise ou metadata PDF ;
- `DSGVO-zertifiziert` ;
- `DSGVO-konform garantiert`.

## 14. Méthode spend-based — limites réglementaires

Formule générale :

`dépense agrégée × facteur d'émission monétaire = estimation CO2e indicative`

Limites :

- la méthode repose sur des dépenses agrégées, pas sur toutes les données physiques réelles ;
- elle ne remplace pas un audit ;
- elle ne constitue pas un inventaire GES complet ;
- elle ne garantit pas la précision d'une comptabilité carbone exhaustive ;
- elle dépend des données déclarées par l'utilisateur ;
- elle doit être décrite comme estimation indicative.

Wording allemand prudent :

| Formulation | Usage |
| --- | --- |
| `ausgabenbasierte Emissionsschätzung` | Méthodologie courte. |
| `auf aggregierten Ausgaben und Emissionsfaktoren basierend` | Explication claire. |
| `keine vollständige Treibhausgasbilanz` | Limite forte. |
| `kein Ersatz für physische Aktivitätsdaten oder ein Audit` | Méthodologie / FAQ. |
| `indikatives Ergebnis in tCO2e` | Résultat. |
